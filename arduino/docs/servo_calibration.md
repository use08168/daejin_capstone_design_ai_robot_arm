# 서보 캘리브레이션 — 펄스 ↔ 각도 매핑

> 각 관절 서보의 **0° / 180° 펄스 폭(µs)** 을 실측해 기록한다.
> 서보 개체마다 펄스↔각도 규격이 다르므로 **관절별로 따로 측정**한다.
> 측정 도구: `arduino/src/main.cpp` 서보 테스트 스케치 (시리얼 명령 `u <ch> <us>` 로 직접 펄스 인가).

---

## 1. 공통 사항

| 항목 | 값 |
|------|-----|
| PWM 드라이버 | PCA9685 (I2C 0x40, 12bit) |
| PWM 주파수 | 50Hz (주기 20000µs) |
| 제어 방식 | PCA9685 레지스터 직접 제어 (Wire), 1카운트 ≈ 4.88µs |
| 카운트 변환 | `count = us × 4096 / 20000` |

### 채널 ↔ 관절 매핑

| PCA9685 채널 | 관절 |
|:---:|------|
| 0 | J1 (base) |
| 1 | J2 (shoulder) |
| 2 | J3 (elbow) |
| 3 | J4 (wrist_pitch) |
| 4 | J5 (wrist_roll) |
| 5 | J6 (gripper_rot) |
| 6 | J7 (gripper, 개폐) |

## 2. 서보 특성 (중요)

이 서보는 **기구적 끝단(hard stop)이 없는 마그네틱(절대 위치) 엔코더 서보**로 확인됨.

- **무전원 시:** 손으로 돌리면 끝 스톱 없이 무한 회전 (기어 손상 아님, 정상).
- **전원 인가 시:** 엔코더가 절대 각도를 읽어 명령 펄스 위치로 복귀(폐루프 위치 제어).
- **함의 ① — 소프트웨어 한계 필수:** 물리적으로 막는 게 없으므로, 관절 한계를 **반드시 코드에서 제한**해야 한다 (한계 초과 시 자기 구조물 충돌·배선 꼬임 위험).
- **함의 ② — 전원 인가 시 큰 스윙 위험:** 전원을 넣으면 명령/엔코더 위치로 복귀하며 **큰 호를 그릴 수 있음** → 안전한 부팅/홈 복귀 전략 필요.
- 펄스를 펄스범위 이상으로 키우면 어느 지점에서 **포화(더 안 움직임)** 된다 → 그 지점이 실질 상한.

| **J2** | 1 | **530** | **2670** | 2140 | ≈ 11.89 | ✅ 확정 |

| **J4** | 3 | **690** | **2800** | 2110 | ≈ 11.72 | ✅ 확정 |
| **J5** | 4 | **620** | **2750** | 2130 | ≈ 11.83 | ✅ 확정 |

---

## 4. 펄스 ↔ 각도 변환식

관절별 `us_0`(0°), `us_180`(180°)를 측정한 뒤:

```
us    = us_0 + (angle_deg / 180) × (us_180 − us_0)
angle = (us − us_0) × 180 / (us_180 − us_0)
```

예) J1, angle = 90° → `600 + (90/180)×(2740−600) = 600 + 1070 = 1670µs`

---

## 5. 측정 절차 (관절 1개 기준)

1. 해당 채널을 중간 펄스로 보내 응답·매핑 확인 (`u <ch> 1500`).
2. 한쪽 끝으로 천천히 이동시켜 **0° 위치의 펄스**를 미세 조정으로 확정.
3. 반대쪽 끝으로 이동시켜 **180° 위치의 펄스**를 확정.
4. 끝 스톱이 없으므로 **포화(더 안 움직이는) 지점**도 함께 기록.
5. 본 표에 기입.
