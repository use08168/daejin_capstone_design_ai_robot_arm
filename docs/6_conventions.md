# 공통 규약 — 좌표계 / 단위 / 명명

> 모든 계층이 동일한 단위와 좌표 약속을 따른다. 변환 버그의 대부분은 단위/좌표 불일치에서 발생하므로 여기서 못박는다.

---

## 1. 단위

| 물리량 | 단위 | 비고 |
|--------|------|------|
| 길이 | **mm** | 예외 없음 |
| 각도 | **degree** (외부 인터페이스) / **radian** (내부 수학) | gRPC/Serial 필드는 `_deg`. IK 내부 계산은 rad. 경계에서 변환. |
| 시간 | gRPC: Unix epoch **ms** / Arduino: `millis()` 상대 ms | |
| 무게 | **g** | |
| 각속도 | **deg/s** | 최대 60 deg/s |

---

## 2. 좌표계

### 2.1 로봇 베이스 좌표계 (기준 프레임)

- 원점: 로봇 베이스 중심
- Z축: 위쪽(중력 반대)
- X/Y: 베이스 평면. ArUco 마커 정렬 기준으로 확정.

### 2.2 작업공간 (config 기준값)

| 축 | 범위 (mm) |
|----|----------|
| x | [-200, 200] |
| y | [50, 350] |
| z | [50, 250] |

### 2.3 카메라 ↔ 로봇 변환

- 카메라 좌표 → 로봇 좌표는 동차변환 행렬 `T`로 통일.
- `T`는 ArUco 외부 캘리브레이션으로 산출, RAG에 저장하여 재사용.

## 3. 관절 명명 및 한계

| 관절 | 이름 | 서보 | 한계 (deg, 초기값) |
|------|------|------|-------------------|
| J1 | base | DS3235 Pro | [-90, 90] |
| J2 | shoulder | DS3235 Pro | [-90, 90] |
| J3 | elbow | DS3218 Pro | [-90, 90] |
| J4 | wrist_pitch | DS3218 Pro | [-90, 90] |
| J5 | wrist_roll | MG90S | [-90, 90] |
| J6 | gripper_rot | MG90S | [-90, 90] |
| — | gripper (개폐) | MG90S | open/close |

> 한계값은 콜드스타트 관절 한계 측정으로 실측값으로 갱신된다.
>
> **실측 갱신(2026-06):** 위 `[-90, 90]`은 원래 설계값이며, 실제 매핑은 각 관절을 **0°~180°** 가동범위로 잡고 관절별 0°/180° 펄스폭 실측값([arduino/docs/1_servo_calibration.md](../arduino/docs/1_servo_calibration.md))을 사용한다. 서보가 **끝 스톱이 없는 마그네틱(절대위치) 엔코더형**(무전원 시 무한 회전, 전원 시 위치 복귀)이라 **소프트웨어 관절 한계가 필수**다.

## 4. PWM 매핑 규약

```
PWM_μs    = 1500 + (θ_deg / 90) * 500     # 0°→1500, +90°→2000, -90°→1000
PCA_value = int(PWM_μs * 4096 / 20000)    # 50Hz=20000μs, 12bit
```

> **주의 — 위 균일 공식은 원래 설계값이며 실측으로 대체되었다.** 실제 매핑은 관절별 실측 0°/180° 펄스폭([arduino/docs/1_servo_calibration.md](../arduino/docs/1_servo_calibration.md), 예: J1 0°=600µs, 180°=2740µs)을 사용하고 가동범위는 **0~180°**다. 서보가 끝 스톱 없는 마그네틱 엔코더형이므로 소프트웨어 관절 한계가 필수다.

## 5. 객체 ID 명명

- 탐지 객체는 `<class>_<index>` 형식 (예: `cup_2`, `book_1`).
- DSL의 `target`은 이 ID를 사용한다 (좌표 직접 지정 금지).
