3 · 자연어 제어 골격 — 추후 구현

한국어 음성/문장으로 로봇팔에 명령하는 화면입니다. 형식만 갖춘 상태이며, 실제 동작은 AI 서버 완료 후 노트북·아두이노·AI 서버 통합 단계에서 구현됩니다.
안녕하세요. (예시) "빨간 컵을 책 옆에 놔줘" 처럼 명령하면 로봇팔이 수행합니다.
빨간 컵을 책 옆에 놔줘
※ 이 응답/동작은 AI 서버 연동 후 활성화됩니다.
예정 처리 흐름
음성/문장 → EdgeXpert(Whisper·Gemma) → JSON DSL → 노트북 검증·IK·삼각측량 → Arduino PWM 실행 → 결과를 이 화면에 표시.
이 페이지는 그 통합 단계에서 gRPC 클라이언트 + DSL 실행기와 연결됩니다.
