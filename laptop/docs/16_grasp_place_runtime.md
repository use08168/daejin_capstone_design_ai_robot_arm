## 0. 한눈에 — 전체 흐름

```
[물체 표시] ──▶ 🧠 AI 파지 ────────────────────────────────┐
                 │ MLP: 수직/수평 + 품질 판정                 │
                 │ _searchObjGrasp: jaw 도달 자세 검색         │
                 │ _refineWrist: 손목(J4~J6) roll 미세조정      │
                 ▼                                            │
        executeGraspTwoStage  ── 이상자세 정렬(가능한 만큼)    │
                 │  ① standoff(접근축 −80mm, 그리퍼 열림)       │ 실패/막힘
                 │  ② 직선 접근 → 닫기 → 물체 부착(_attachObj)   │   ▼
                 │  ③ 들기(+100mm)                             │ _directGrasp(폴백)
                 ▼                                            │ 이동+닫기+부착+들기
        [_held = 물체 부착됨] ◀───────────────────────────────┘
                 │
                 ▼  📥 여기 놓기
        executePlace  ── 자이로 수평 레벨링(접근 수평 시)
                 │  ① 들어올림  ② 운반(목표 위, 바닥 회피)
                 │  ③ 하강 → 열기 → 분리(_detachObj)
                 │  ④ 후퇴
                 ▼
              [놓기 완료]
```

핵심 상태값:
| 변수 | 의미 |
|------|------|
| `vObj` | 가상 물체(THREE.Mesh, 프리미티브 sph/cyl/box) |
| `_held` | 잡고 있는 물체. `{localPos}` = 부착 시점 TCP-로컬 오프셋. null=빈손 |
| `graspSeq` | 실행 중 시퀀스 `{steps:[{joints,grip,label}], i}` |
| `gjaw` | 가상 jaw(노란 면) 박스. TCP 기준 파지 판정의 기준틀 |

## 1. 저수준 빌딩블록

### 1-1. 연속 자세 IK — `_ikToPose(j0, tPos, tQuat, iters, ow)`
주어진 시작 관절 `j0`에서 **목표 TCP 위치 `tPos` + 자세 `tQuat`**로 수렴시키는 국소(hill-climb) IK.

```
비용 _poseErr = |위치오차(mm)|  +  자세오차(도) × ow
```
- 6개 관절을 ±step(12°→0.4°)으로 좌표하강, 개선 없으면 step 절반.
- 반환: `{j(관절), err(비용), posErr(mm), angErr(자세 잔차°)}`.
- **`ow`(orientation weight, 기본 1.5)가 핵심 손잡이.** 클수록 위치보다 자세 정렬을 우선 → 같은 위치를 맞추되 **손목(특히 J6)을 더 돌려** 노란 면을 원하는 방향으로 유지한다. → 놓기 자이로(§4)에서 `ow=4` 사용.

연속(continuous) IK인 이유: standoff→접근→들기처럼 **이전 자세에서 조금씩만 움직이는** 경로를 만들기 위해. 매번 전역 검색하면 자세가 튄다.

### 1-2. 보조
| 함수 | 역할 |
|------|------|
| `_tcpOfJoints(j)` | 관절 `j`의 TCP 포즈 `{pos,q}` 계산 후 **자세 원복**(부작용 없음) |
| `_tcpPose()` | 현재 적용된 관절의 TCP 포즈 `{ok,pos,quat,approach,part}` |
| `pathClear(jA,jB)` | 두 자세 사이 직선 보간 경로가 충돌 없는지 |
| `seqNext()/seqStepDone(st)` | 시퀀스 한 스텝 실행. `grip:'close'`→`setGripper(1)`+`_attachObj()`, `grip:'open'`→`setGripper(0)`+`_detachObj()` |

상수: `GRASP_STANDOFF=80mm`(프리그래스프 후퇴), `GRASP_LIFT=100mm`(들기 높이).

## 2. 두 단계 집기 — `executeGraspTwoStage(Gj, label, approach, O)`

> 입력: `Gj`(파지 후보 관절), `approach`('vert'|'horz'), `O`(물체 중심 월드).
> 한 번에 물체로 돌진하지 않고 **standoff에서 정렬 → 직선으로 접근**한다(노란 면 꺾임·측면 충돌 방지).

1. **이상 자세 정렬(가능한 만큼).** 후보 `Gj`의 TCP 자세를 그대로 쓰지 않고 *이상적 방향*으로 재정렬을 시도:
   - 수직: 접근축 z=`(0,−1,0)`(정아래), 노란 면 수평.
   - 수평: 접근축 z=수평으로 **물체 중심을 향함**, 손가락축 y=수직.
   - 이상 자세 `qi`로 "물체가 jaw 중심(`gjaw.cx,cy,cz`)에 오는" TCP를 `_ikToPose`로 풂.
   - `posErr<25mm`면 채택, 남은 자세 잔차 `angErr`를 **기울기(tilt)**로 보고. → 구조적으로 완전한 수직/수평이 안 되는 위치에서도 "**할 수 있는 만큼**" 정렬하고 한계를 숫자로 드러냄.
2. **standoff.** 실제 도달한 접근축 A를 따라 `−80mm` 뒤 지점으로 `_ikToPose` → 프리그래스프 자세(그리퍼 열림).
3. **경로 검사.** `pathClear(pre, G)`로 직선 접근이 충돌 없는지. 막히면 → `_directGrasp(원본 G)` 폴백.
4. **시퀀스 생성:**
   - ① 프리그래스프(정렬) — `grip:'open'`, 라벨에 기울기° 표기(>15°면 "팔 구조 한계").
   - ② 직선 접근·파지 — `grip:'close'` → 부착.
   - ③ 들기(+100mm).

### 폴백 — `_directGrasp(Gj, label)`
두 단계가 불가(standoff 못 풂/경로 막힘)할 때: 후보 G로 **직접 이동 + 닫기 + 부착**, 도달되면 들기까지. (초기 버전은 닫기/부착을 빠뜨려 "잡았는데 안 들림" 버그가 있었음 → §6 참조.)

## 3. 충돌 인식 — 손가락은 허용, 몸체는 금지

파지 자세가 **그리퍼 몸체(손가락 제외)나 팔이 물체를 파고들면** 무효다. 물체를 손가락 사이가 아니라 손등/링크로 "밀고" 있는 가짜 파지를 거른다.

| 함수 | 방식 | 용도 |
|------|------|------|
| `_gripperHitsObject(invObj,type,R,H)` | grip 체인 중 **손가락 제외** 메시 정점을 물체 SDF로 검사, 3mm↑ 침투=충돌 | 정밀(관절 적용) |
| `_bodyHitsObject(pos,quat,...)` | TCP 프레임에 사전계산한 몸체 점군 — 관절 적용 없이 빠름 | 대량 라벨링/검색 |
| `_evalGraspFull(j,...)` | jaw 품질 + 몸체 충돌, `cost += 충돌?500` | 최적 자세 탐색 |

> SDF(`_objSDF`): sph=구, cyl/cup=원기둥(측면 부호거리), box=상자. 물체-로컬(중심 원점, 축=Y) 기준.

## 4. 놓기 — `executePlace()` (J6 자이로 수평 유지)

> 든 물체(`_held`)를 `(plX, plY, plZ)`에 안전하게 내려놓는다. **공중 좌표·바닥 쓸기·물체 기울어짐**을 모두 방지.

1. **놓을 높이.** `plY` 비면 `floorY + H/2`(바닥에 안착).
2. **🔑 자이로 레벨링.** 현재 든 자세의 접근축 z가 수평에 가까우면(`|z.y|<0.7`) **손가락축 y를 수직(up)으로 재정렬**한 자세 `q`를 만든다 → 노란 면이 꺾이지 않고 수평 유지. (수직 파지는 이미 똑바라 생략.)
3. **`ow=4`로 IK.** 들어올림→운반→하강 세 구간 모두 자세 가중치를 높여 `_ikToPose(..., 90, OW)` → **J6가 충분히 회전**해 운반 내내 jaw 수평을 유지. (이전엔 위치만 맞추느라 J6를 덜 돌려 물체가 기울었음.)
4. **운반 높이** `transY = max(현재y, 목표y) + 90mm` → 가는 길에 바닥/물체를 쓸지 않음.
5. **물체 추적 오프셋** `offW = _held.localPos ⟲ q`. `tcpFor(물체중심)=물체중심−offW` 로 물체가 목표에 오도록 TCP 목표를 역산.
6. **시퀀스:** ① 들어올림 ② 운반(목표 위) ③ 하강+`grip:'open'`(분리) ④ 후퇴. 도달오차 40mm↑면 "도달 불가 — 접근맵 가능구역으로" 거부.

### 부착/추적 — `_attachObj / _updateHeld / _detachObj`
- `_attachObj()`: 닫는 순간 물체의 TCP-로컬 오프셋을 `_held.localPos`로 고정(강체 부착).
- `_updateHeld(t)`: 매 프레임 물체를 TCP에 붙여 따라가게 하고, **IK 목표(ikX/Y/Z)도 든 물체로 갱신** → "물체 옮겼는데 놓기 좌표가 안 따라옴" 해결.
- `_detachObj()`: 열기 시 분리.

## 5. 운영 도구 (가상 물체 카드 버튼)

| 버튼 | 함수 | 동작 |
|------|------|------|
| 🧠 AI 파지 | `aiGrasp` | MLP가 수직/수평+품질 판정 → 접근 선택(자동/강제) → `_searchObjGrasp`로 자세 검색 → `_refineWrist` → 두 단계 집기. **주 진입점.** |
| 🎯 최적 자세 찾기 | `optimizeGraspForObject` | 물체 고정, 근처 DB 자세를 **전수 평가**(jaw 쏙+충돌없음+깊이) → 최적 1개 → 손목 정밀화 → 실행. MLP 없이 그 위치 한계 확인용. |
| 🗺 접근맵 | `approachMap` | 이 물체 크기로 워크스페이스를 격자 스캔, 각 셀에서 수직/수평 도달 기울기<20°인지 → **파랑(수직)·초록(수평)·청록(둘다)** 구슬. `approach_map.csv` 저장. |
| 📥 여기 놓기 | `executePlace` | §4 |

### 손목 정밀화 — `_refineWrist(j0, ...)`
J4·J5·J6만 ±step으로 hill-climb해 jaw 정렬 cost 최소화(roll 포함). 충돌 시 원본 복귀.
근거: 6-DOF 파지 샘플링의 'roll 각도' 최적화(approach-based/antipodal). DB 밀도 한계를 국소 보정. → [13 §9 참고문헌](13_grasp_learning_mlp.md).

### 접근맵이 드러낸 구조적 한계
접근맵 결과: **도달 가능 영역이 환형(annular)** — 팔에서 적당히 떨어진 링에서는 수직/수평이 되지만, **베이스 바로 앞(근접부)은 수직 파지 사각지대**. 이는 MLP의 한계가 아니라 **6-DOF 팔의 기구학적 구조 한계**다(짧은 링크로 베이스 근처에서 손목을 정아래로 못 세움). 실전 배치 시 물체를 이 가능 구역 안에 두는 것이 전제.

## 6. 해결한 버그 (실행 계층)

| 증상 | 원인 | 해결 |
|------|------|------|
| 두 단계 "충돌없는 경로 없음"인데 P2 제어로는 도달 | 직선 접근이 경로 라우팅보다 엄격 | `pathClear` 검사 → 막히면 `_directGrasp` 폴백 |
| 폴백으로 가니 **그리퍼가 안 닫히고 물체도 안 들림** | `_directGrasp`가 이동만 함 | 닫기(`grip:'close'`)+`_attachObj`+들기 스텝 추가 |
| 놓기 시 IK 목표가 **든 물체를 안 따라감** | ikX/Y/Z가 잡기 전 값 고정 | `_updateHeld`가 ikX/Y/Z를 든 물체로 갱신 |
| 놓기 Y가 **공중**, 운반 중 **바닥 쓸기** | plY 없음/단일 웨이포인트 | plY 입력 + 들어올림→운반→하강 4스텝 |
| 운반 중 물체가 **기울어짐**(J6 덜 돌림) | IK가 위치만 우선(`ow` 낮음) | 자이로 레벨링 + `ow=4` (§4) |

## 7. 다음 단계 (AI 서버 연동)

`[pick(object_id), place(target_xyz)]` → 4페이지 `aiGrasp`/`executePlace` 호출. 상세는 [7_ai_integration.md](7_ai_integration.md) 및 ai-server 측 문서에서 이어간다.
물체 **자세(orientation) 부착**(현재는 위치만), 버튼 통일(🧠을 단일 주버튼으로 🔬/🎯 흡수)이 후속 과제.
