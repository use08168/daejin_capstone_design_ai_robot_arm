# 물체 파지 파이프라인 — FK 샘플링 기반 파지 DB · 6DOF IK · 방향 조건부 도달영역

> **요지:** 정밀 DH 해석적 IK 대신, **보정된 디지털 트윈(arm3d)으로 그리퍼 자세를 샘플링**해
> "관절각 ↔ 그리퍼 TCP 포즈(위치+방향) ↔ 충돌" 데이터베이스를 만들고, 이를 역으로 풀어
> **물체 위치 + 접근 방향(수직/수평) → 충돌 없는 관절각**을 얻는다. 같은 위치라도 접근 방향마다
> 도달 가능 여부가 다르므로(**capability map**), AI가 명령할 때 접근 전략 자체를 데이터로 결정한다.

관련: [6_digital_twin_safety.md](6_digital_twin_safety.md) · [8_arm3d_simulator.md](8_arm3d_simulator.md) · [3_coordinate_3d_pipeline.md](3_coordinate_3d_pipeline.md)

## 1. 전체 구조 — 이미 가진 것 위에 얹는 "도달·파지 층(L1.5)"

```
인식(스테레오→3D좌표, 로봇 기준)  ──┐
                                    ├─▶ capability map: 이 위치에서 수직/수평 가능?
파지 DB(FK 샘플링, arm3d)  ─────────┘            │ 접근 선택
   │                                             ▼
   └─▶ 6DOF IK: (물체 위치 + 접근 자세) → 관절각  ──▶ 경로계획(접근→하강→파지→들기)
                                                        │ 충돌검증(C-space)
                                                        ▼  아두이노
```

기존 자산을 그대로 재사용한다: **arm3d 보정 FK + 충돌코어 `_collideOnce` + sim-real 마진(바닥 30mm)**.
C-space 충돌맵과 달리 파지에선 **J1(방위각)을 포함**한다.

| 역할 | 관절 | 결정 |
|------|------|------|
| 방위각(물체 방향) | J1 | ≈ atan2(obj_y, obj_x) |
| 도달 거리·높이 | J2·J3 | 수직평면 도달 |
| 그리퍼 방향(수직/수평) | J4·J5·J6 | 손목 자세 |

## 2. 그리퍼 TCP(파지 중앙점) 정의 — P0

그리퍼가 물체를 잡는 **기준점(TCP)** 과 그 **좌표 프레임**을 정의한다 (`arm3d.html`).

- **수동 지정:** 기준 STL 부품 선택 → XYZ 위치 + RXYZ 회전 미세조정 → ✓확정. 부품 **로컬좌표로 저장**(`localStorage armTCP_v1`)되어 관절 따라 정확히 이동.
- **강체 프레임(핵심):** 확정 순간의 프레임 방향을 **부품 로컬 쿼터니언(lq)으로 구워서** 저장 → `프레임 = 부품 현재자세 × lq` → 그리퍼가 회전해도 좌표축이 **강체로 정확히 따라감**(모든 각도 일관, 0/90/180 샘플링 불필요).
- **표시:** 시안 마커(파지점) + 3축 triad(z=파랑=접근축). 손목 회전 시 축이 그리퍼를 따라 회전.
- 자동 추정 모드(손가락 끝 군집 중심)도 있으나, **수동 확정 권장**.

## 3. 관절 회전축 보정 — 리깅 정확화 (FK 토대)

자동 면결합으로 잡은 **회전축(`m.axis`)·피벗(`m.pivot`)** 의 작은 오차가 관절 회전 시 **비틀림으로 증폭·누적**되어 그리퍼/TCP가 틀어진다. 부품은 강체로 붙어 슬립은 없고, **축 오차가 유일한 원인**.

관절 편집(결합 모드)에 추가된 보정 도구:

| 도구 | 역할 |
|------|------|
| 위치보정(aox/y/z) | 부품 서브트리 이동 |
| roll° | 축 둘레 롤 |
| **축기울기** X/Y/Z | 회전축 **방향** 미세회전(비틀림 제거) |
| **축위치** X/Y/Z | 회전중심(피벗) **이동**(궤도 정렬) |

→ 관절당 **위치+롤+축방향+축위치 = 6DOF 완전 보정**. **선택 관절의 회전축을 크게 시각화**(z=파랑 triad + 노란 축선 ±240)하여 눈으로 보며 조정. **끝각(0/180°)에서** 비틀림이 최소가 되게 맞추고 💾 저장(축 무관한 휴식 90°에선 효과 없음).

> 정확한 축 → FK·C-space·파지 데이터·TCP가 모두 정밀해진다. (향후 콜드스타트 screw axis로 자동화 가능.)

## 4. 파지 데이터셋 — P1 (FK 샘플링)

4페이지 **파지 스윕(J1~J6)** 버튼: 관절을 무작위로 쓸어 각 자세를 기록 → `grasp_dataset.csv`.

| 컬럼 | 의미 |
|------|------|
| `J1`~`J6` | 관절각 |
| `tcp_x,y,z` | 그리퍼 TCP 위치(mm, y가 위) |
| `app_x,y,z` | 접근 단위벡터 = 프레임 z (수직 app_y≈−1, 수평 |app_y|≈0) |
| `qx,qy,qz,qw` | **그리퍼 프레임 전체 자세(쿼터니언)** — 6DOF IK용 |
| `floor_clear_mm` / `self_clear_mm` | 바닥/자기 충돌 여유 |
| `collision` | 1 = 충돌(잡기 후보 아님) |

`_collideOnce`·`_csDownload` 재사용으로 **sim-real 일관성** 유지. 10만 샘플 권장(충돌 ~9%).
> 회전 오프셋·강체 프레임을 바꾸면 **재스윕**해야 데이터가 일치한다.

## 5. 도달영역 분석 — `calibration/grasp_analysis.py`

`grasp_dataset.csv` → 충돌 없는 TCP 점군의 3D 산점(파지방향별 색) + 높이별 X-Z 도달영역.

```
python calibration/grasp_analysis.py <csv>
  → docs/image/grasp-reach3d.png, grasp-reach-top.png
```

**100k 실측:** 충돌 없음 91.3%, 작업공간 반구형(X[−415,384] Y[16,527] Z[−407,406]).
**IK 최근접 잔차**(밀도 척도): 전체 중앙 **5.4mm**, 수직 8.8 / 수평 7.5mm → sim-real 마진 안.

## 6. 6DOF 파지 IK — P2 (시뮬 내 인터랙티브)

4페이지 **파지 IK** 카드: 목표(물체) **프레임**(위치 + 접근 자세) → 데이터셋에서 가장 가까운 충돌 없는 관절각을 찾아 팔 이동.

- **목표 = 좌표 프레임**(주황): XYZ 이동(버튼/입력) + **수직↓/수평→ 프리셋** + **RX/RY/RZ** 회전
- **매칭:** 6DOF 데이터(쿼터니언)면 **목표 프레임 전체와 매칭**(45° 이내) → roll까지 맞춰 **의도한 접근 자세**로 잡음. 구버전 CSV(접근축만)는 폴백.
- **결과:** `위치 잔차 mm · 자세 오차 ° · 관절각`. 위치 45mm 초과 = 도달 어려움.
- 자동 모드: 목표를 옮기면 관절이 실시간 추종.

> **교훈:** 위치만 맞추면 손목이 아무렇게나 꺾인 자세도 통과한다(예: J4=149,J5=155). 깔끔한 파지(예: J4=0,J5=0,J6=90)는 **전체 자세 매칭**이 필요 → 데이터셋에 쿼터니언 기록.

## 7. 방향 조건부 도달영역(capability map) — `calibration/grasp_reachability.py`

**같은 위치라도 수직으로 잡을 수 있는 영역과 수평으로 잡을 수 있는 영역이 다르다.** 이를 복셀로 정량화.

```
python calibration/grasp_reachability.py <csv> [voxel_mm=35] [minN=2]
  → docs/image/grasp-capability3d.png (수직만/수평만/둘다) + grasp_capability.json
python calibration/grasp_reachability.py <csv> --query X Y Z [r=45]   # 그 위치 가능 접근
```

**100k 실측:** 수직만 312 · 수평만 854 · 둘다 2466 복셀 → 접근 가능성이 **위치 의존**임을 입증.
런타임 조회는 **반경 스캔**(복셀 가장자리 과엄격 회피). 예) `(−115,120,−400)` → 수직(11)·수평(18) 둘 다 가능, 최근접 11mm.

## 8. AI 명령 → 접근 전략 결정 흐름 (목표 통합)

```
AI(VLM): 물체 인식 + 3D좌표 + 모양기반 선호(납작→수직 / 길쭉→수평)
   → 노트북: capability map 조회 — 이 위치 수직? 수평? 가능?
       · 선호 가능 → 그대로  · 선호 불가·다른쪽 가능 → 전환(통보)  · 둘 다 불가 → 미도달 보고
   → 6DOF IK: 선택 접근의 파지 자세(관절각)
   → 경로계획(P4): 프리그래스프(접근축으로 떨어진 곳, 그리퍼 열림) → 직진 → 닫기 → 들기  [충돌검증]
   → 아두이노
```

capability map = **AI의 접근 타당성 검증층**(C-space 충돌검증층과 같은 역할 — 불가능한 파지 명령 차단).
