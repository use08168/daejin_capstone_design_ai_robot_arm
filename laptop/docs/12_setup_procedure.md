# 초기 셋업 절차 — 캘리브레이션 + 로봇 위치 파악 (6단계)

> 작업 환경 **최초 세팅 시 1회** 수행. 핵심 원칙: **카메라를 먼저 고정·보정한 뒤 로봇을 설치**한다.
> (①②③은 로봇 없이 → 로봇 설치 → ④⑤⑥). 각 단계 상세 수식은 [3_coordinate_3d_pipeline.md](3_coordinate_3d_pipeline.md) 참조.

---

## 사전 준비물

- **ChArUco 보드** 인쇄(`calibration/calibration_targets.pdf` 1쪽), 평판에 평평히 부착
- **로봇 마커** 인쇄(`calibration/arm_markers.pdf`): 베이스 id0(70mm), 추적 id1~12(40mm) — [13_aruco_markers.md](13_aruco_markers.md)
- **카메라 2대**: 서로 리지드하게 고정(같은 프레임 권장), 작업면에서 **0.5~0.9m**, 대각선 위에서 내려다보게

---

## 순서 개요

```
[카메라 고정·겨냥]
   → ① ChArUco 촬영  → ② 카메라 캘리브레이션  → ③ 3D 검증   (로봇 없이)
   → [로봇 설치]
   → ④ 베이스 마커 부착  → ⑤ 카메라→로봇 변환 T  → ⑥ 관절/작업공간 파악
```

---

## 6단계

### 1단계 — 카메라 배치 & ChArUco 촬영
- **목적:** 캘리브레이션 입력 데이터 확보.
- **할 일:** 카메라를 **로봇이 놓일 자리**를 겨냥해 고정(이후 이동 금지). 로봇 없이 ChArUco 보드를 그 작업 볼륨에서 **위치·기울기(30~45°)·거리**를 바꿔가며 **20~30쌍** 촬영. (도구: 캘리브레이션 페이지의 촬영 기능)
- **완료 기준:** 양쪽 양호 **25쌍 이상**, 화면 가장자리까지 커버리지 양호, 기울임 포즈 포함.

### 2단계 — 카메라 캘리브레이션 산출
- **목적:** 내부(K·왜곡) + 스테레오(R·T) 파라미터.
- **할 일:** `calibration/calibrate_stereo.py` 실행.
- **완료 기준:** 내부/스테레오 **재투영오차 < 1px**, 베이스라인이 실제 카메라 간격과 일치 → `stereo_calib.npz` 저장. (현재값: 0.44/0.49/0.60px, 588mm)

### 3단계 — 3D 정확도 검증
- **목적:** 삼각측량이 실제 mm를 맞히는지 확인.
- **할 일:** `calibration/validate_triangulation.py` 실행 (보드 30mm 칸 복원 오차 측정).
- **완료 기준:** **거리 오차 < ~2mm, 스케일 ≈ 1.0**. (현재값: 0.32mm, 0.9998) → 여기까지 통과하면 **카메라 3D 파이프라인 완성**.

### 4단계 — 로봇팔 배치 & 베이스 마커 부착
- **목적:** 로봇을 작업 위치에 설치하고 기준 마커 부착.
- **할 일:** 1단계에서 겨냥했던 자리에 로봇 설치. **움직이지 않는 베이스**에 **id0(70mm)** 부착, **양 카메라에 보이게**. 팔은 **홈(접은) 자세**로 두어 베이스 마커를 안 가리게.
- **완료 기준:** 양 카메라가 id0 마커를 안정적으로 검출.

### 5단계 — 카메라→로봇 변환 T (움직이지 않는 부분)  ✅ 구현
- **목적:** 카메라 좌표 → **로봇 베이스 좌표** (IK가 쓰는 기준).
- **할 일:** 2페이지 4단계에서 id0가 **좌·우 동시 검출**(✓)되는지 확인 → 5단계 **[변환 T 산출]** 클릭.
  - 내부: 양 카메라로 id0 네 코너를 **삼각측량** → 마커 평면으로 로봇 기준 프레임 정의 → `T`(4×4) 저장(`calibration/camera_robot_T.npz`). 마커 변 길이가 70mm 근접인지로 sanity 체크.
- **완료 기준:** T 저장 후 **1페이지 3D 좌표가 로봇 기준 mm**(`frame:"robot"`)로 표시됨.
- 모듈: `armvision/markers.py`(DICT_6X6_250 검출 + T), `stereo3d.py`(T 적용).

### 6단계 — 로봇 관절 위치 파악 (움직이는 부분) + 작업공간
- **목적:** 각 링크/그리퍼 위치 추적의 토대 + 작업공간 범위 확정.
- **할 일:** 추적 마커 **id1~**로 각 링크/그리퍼 포즈 측정(콜드스타트 운동학 보정 토대), 도달 가능 **작업공간 x/y/z 범위** 기록.
- **완료 기준:** 관절 위치·작업공간 정보 확보 → "현재 작업 환경 기본 정보" 확정.
- *(구현 예정 — 추적 마커 부착 후)*

## 재수행 기준

| 무엇이 바뀌면 | 다시 할 단계 |
|--------------|-------------|
| 두 카메라가 서로 움직임 | ① ② ③ (그리고 ⑤) |
| 카메라↔로봇 상대위치 변경 | ⑤ (필요시 ⑥) |
| 렌즈 초점/줌 변경 | ① 부터 |
| 로봇만 살짝 이동 | ⑤ ⑥ |

> 한 번 통과하면 결과(`stereo_calib.npz`, T 등)를 저장해 재사용. 위 변화가 없으면 매번 할 필요 없음.

**새 환경으로 다시 보정:** 2페이지의 **🔄 새 환경으로 초기화** 버튼 → 기존 촬영본·캘리브레이션을 타임스탬프 폴더(`captures/_archive_*`, `calibration/_archive/`)로 **보관**하고 0부터 다시 시작한다(삭제 아님, 복구 가능). 보정 완료 전까지 1페이지 3D 좌표는 비활성.
